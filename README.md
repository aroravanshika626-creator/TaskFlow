# TaskFlow

A full-stack task management web application that helps users organize, track, and manage their tasks efficiently.

## Features

- User registration and login
- JWT-based authentication
- Protected routes
- Create, edit, and delete tasks
- Mark tasks as completed
- Separate completed tasks view
- Personalized dashboard
- User-specific task data
- Responsive and clean user interface

## Tech Stack

### Frontend
- React.js
- React Router
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
